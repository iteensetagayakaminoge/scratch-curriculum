# 23. WEB上でのSTEP表示

教材上のSTEP順序は変更しない。

ただしAntigravityは、読みやすさのためにSTEP内部を分割してよい。

例：

教材仕様：

`STEP 3 重力ジャンプ`

WEB表示：

- 3-1 ジャンプしよう
- 3-2 下に落ちるようにしよう
- 3-3 地面で止めよう

この場合も教材上はSTEP 3として扱う。

# 24. Claude Code向け実装注意事項

Claude Codeは本仕様を変更せず実装する。

実装前に必ず以下を確認する。

- lesson_id
- spec_version
- 使用基礎ID
- 使用ギミックID
- STEP構成
- Scratchコード設計
- 開始用作品
- 完成用作品
- 必要素材

Scratchコードは、

**生徒が理解しやすいこと**

を優先する。

高度な最適化や複雑な処理で簡略化しすぎない。

技術的問題がある場合は、実装を開始・継続せずチャッピーへ差し戻す。

# 25. Antigravity向け実装注意事項

Antigravityは、本仕様に基づき生徒向けWEB教材を制作する。

WEB上の見せ方・UI/UXは改善してよい。

以下は独自改善可能。

- STEP内部の表示分割
- レイアウト
- ヒント表示

- カード表示
- レスポンシブ対応

ただし、

- 学習内容
- STEP順序
- Scratchコード
- 使用するブロック
- 完成条件
- LEVEL
- 教材ID
- 基礎ID
- ギミックID

は独自変更しない。
